# 番剧详情与地图聚焦

详情 sheet 默认打开到 80% 时只展示内容，地图保留原有相机与点位。用户稳定降到 25% 后，才首次筛选该番剧并定位全部有效点位；重新拉高不会取消筛选或重复定位。关闭详情清除筛选，不移动相机。

`openedBangumiDetailsId` 管理详情会话，`filteredBangumiId` 管理已经应用到地图的番剧范围。搜索和点位卡标题等所有详情入口共用这套行为。同一会话跨页返回保留档位、滚动位置和筛选状态；真正关闭后再次打开仍从 80% 开始。

详情内点选同时应用筛选和一次性 `point` 相机请求。随后的 `resize(0)` 不再补发 `bangumi-overview`，避免整番剧定位覆盖点位定位。两类请求由首页统一消费，执行前核对当前页面焦点和实时请求 ID；关闭仅取消待执行的 overview，保留原有点位弹窗语义。

普通点、图片点与番剧 icon 图层读取已应用的筛选；顶部详情条、控件显隐与返回关闭仍读取详情会话。计划地图继续使用显式传入的筛选，不受首页详情影响。TrueSheet 保持 3.11.18 和现有会话关闭保护。

自动化测试覆盖 store 原子更新、重复降档、过期请求、旧会话和失焦/关闭回调，以及 overview 坐标边界。手势、动画、旋转与 3D 下的实际体验需设备验收；此调整单独提交，便于整体 revert。
