# 卡片列表布局

作品、点位、计划卡片及收藏作品网格共用以下规则。适用于 FlashList、LegendList、SectionList 和普通布局；不改变各容器的数据、回收或滚动逻辑。

## 职责与尺寸

- 卡片本体负责背景、圆角、阴影、内容裁剪及交互，不带用于排列的外部 margin。
- 列表项使用 `src/components/ui/card-list-item.tsx` 的 `CardListItem`。外壳透明，上下各留 4，给阴影提供绘制空间；相邻卡片的间距为 8。不要再叠加同用途的 separator、gap 或 margin。
- `horizontalInset` 表示页面横向内边距。网格用 `grid`：每个单元上下左右各留 4，横纵间距均为 8，并占满分配给该单元的宽度。
- 阴影、留白及行高计算统一定义在 `src/lib/card-list-layout.ts`。修改阴影扩散范围时应一起核对留白。
- 固定行高使用 `getCardListItemHeight(卡片高度)`。计划详情的普通卡片与拖拽预览分别从自身高度推导总高度；排序和普通模式保持相同组件结构。

## 页面与分组边界

列表项的留白也算在卡片到标题、工具栏和容器边缘的距离内。已有留白的地方使用 `getCardListBoundarySpacing(期望总间距)`，不能把完整页面间距再叠到外壳上。例如，期望总间距为 13，容器只提供 9，剩下 4 来自列表项。小于 4 的总间距会保留最小阴影空间 4。

- 普通列表：在 `contentContainerStyle.paddingTop` 或列表上方的容器中安排边界留白，只选一处。
- 分组列表：标题独立渲染，只有实际卡片使用 `CardListItem`。标题底部已有留白时计入外壳的 4；末项下方也已有 4，不再重复提供同一份留白。空组、折叠组不生成占位卡片。
- SectionList：`ItemSeparatorComponent` 与 `SectionSeparatorComponent` 不重复提供卡片项间距。标题和页脚可保留有意设计的分组距离。
- 吸顶标题需要保留不透明背景及原有高度、偏移；滚动中的卡片被标题遮住是正常行为。地图作品详情的控件吸顶、折叠与滚动恢复继续由原实现管理。
- 网格：列表横向 padding 使用 `getCardListBoundarySpacing(页面边距)`，加上单元自身的 4 后，卡片边缘与单列列表对齐。不要再给卡片加横向 margin。
- 安全区、底部导航和固定页脚的空间由页面管理，不拿来计算卡片项间距。

## 使用范围

已接入搜索、巡礼计划列表、计划详情与拖拽预览、收藏作品网格与收藏历史、两处作品收藏路由、从收藏添加点位、批量添加中的作品及分组选择行、地图作品详情、计划地图点位列表。

设置行、计划选择弹层、菜单行和开源依赖列表保持连续行及分隔线布局。地图浮动卡片、横向筛选控件、相机选项和分享图不使用竖向卡片列表布局。

## 真机回归

- 普通列表首尾阴影，首项与搜索框、标题或工具栏之间的距离；浅色和深色模式。
- 收藏三列网格的横纵间距、未满一行及网格/历史模式切换。
- 分组首末项、仅一项、空组、全部折叠、重新展开、连续吸顶标题切换。
- 计划详情排序开关、拖拽首末项、自动滚动、插入线与落点，以及图片和点击区域。
- 计划地图列表打开定位、末尾项定位、筛选切换；地图作品详情分组模式切换及滚动位置恢复。
- 原 ScrollView 作品收藏路由的长列表回收、快照失效点位、移除收藏、图片预览及返回地图。

类型、lint 与格式检查不证明以上原生视觉及手势行为。
