# 图片预览：接入与回归验证

使用 `react-native-zoom-toolkit` 5.1.1 的 `ResumableZoom` 和项目已有的 `expo-image`。单击、双击和翻页由预览组件协调，未修改第三方依赖，也不需要安装补丁。

## 已接入的业务入口

- 首页地图：选择点位后，点击弹出卡片中的截图。
- 巡礼计划地图：点击当前点位卡片中的截图。
- 巡礼点列表：收藏、番剧详情、搜索、计划详情、添加点位、计划地图点位列表共用 `PointListCard`。
- 番剧封面：搜索页番剧列表项、番剧详情底部面板的顶部封面。

巡礼点入口统一使用 `PointImage`：优先显示截图，没有截图时显示番剧封面并叠加“暂无截图”，封面同样允许预览原图。截图和封面都不存在时仅显示提示，不打开预览。收藏和计划快照分别传入截图、封面，避免把封面当作截图。番剧封面直接使用 `PreviewableImage`，不叠加缺少截图的提示。缩略图加载完成后从 `onLoad` 获取图片比例，不把卡片裁切后的比例当作原图比例。缩略图尚未加载或加载失败时也可立即打开预览：先淡入，原图加载后补齐比例。

列表图片与文字区操作分开：点击图片只预览，文字区保留地图跳转或点位添加等原操作。列表滚动不应触发预览；计划排序和拖拽浮层关闭预览。需复测无截图封面预览、原图保存/分享、回收条目切换图片、收藏按钮与列表原操作。

额外验收：点击收藏仍只切换收藏；点击集数/时间区域可预览；计划卡片横滑和前后切换仍正常，切换后打开的截图应与当前点位一致。预览返回后当前点位、卡片位置和操作状态保持不变。

计划卡片继续使用 Gesture Handler 的 `Pressable`，由父级 RNGH 横滑接管时取消按压。首页 Popup 位于 Mapbox `MarkerView` 内，设备反馈普通 `Pressable` 拖动仍会误触，因此首页传入 `maxPressDistance={8}`，内部改用 Tap 手势，在移动超过 8 个逻辑像素时直接失败，不依赖地图取消按压。

设备复测：首页从图片开始横拖、竖拖、斜拖、拖出再拖回，超过阈值后均不应打开预览；松手后再次正常点击应打开，地图拖动与预览动画保持正常。计划卡片复测慢拖、快滑、横滑激活后回弹；未达到父级横滑激活阈值的短距离移动可能仍被识别为点击。两处均需检查屏幕阅读器激活。

## 独立演示入口

开发模式下打开 `/image-preview-demo`。演示页没有加入业务菜单；生产模式访问该路由会返回首页。

已连接 Android 设备并自行启动开发应用后，可通过深链接打开：

```powershell
adb shell am start -a android.intent.action.VIEW -d "anitabiapp-dev://image-preview-demo"
```

生产变体的开发会话使用 `anitabiapp://image-preview-demo`，测试变体使用 `anitabiapp-test://image-preview-demo`。页面依赖 `__DEV__`，发行版无法打开。

示例图片来自 Picsum，需要网络。演示包含横图、竖图、长图、单图和故意失败的图片。

## 设备验收

- 点击不同缩略图：从对应位置展开，初始页码正确。
- 快速加载或重复打开已缓存图片：底部不应闪现 loading；当前图片等待超过 300 毫秒才显示加载指示。切图、重试时重新计时，加载完成、失败或关闭后取消计时。
- 单击、关闭按钮、Android 返回键：退出一次，回到演示页。
- 关闭瞬间图片不应先消失再出现；分别检查原图加载完成、仍在加载、加载失败、刚切图和刚打开就关闭的场景。有有效缩略图位置和图片比例时收回，否则淡出，动画时长均为 240 毫秒；结束后留出渲染帧再移除弹窗。图库尚未准备好就关闭时直接退出。
- 缩略图尚未加载或加载失败：点击仍打开预览；原图加载完成后按真实比例显示，关闭后可以再次打开。
- 双击图片不同位置：围绕点击位置放大，再次双击恢复。
- 先双指捏合到 1.5、2、3 倍后双击：直接恢复到 1 倍并居中，不应继续放大到 6 倍；复原后再次双击仍可放大。
- 双指缩放后拖动：边界正常，拖动不会意外触发关闭。
- 放大后拖到图片水平边缘再继续拖动：可切换相邻图片；放大状态下竖向拖动不能关闭预览。
- 左右快滑和慢拖：切换图片，页码正确，切图后缩放重置。
- 原始尺寸下轻拉并松手：回弹；向下拖动足够距离或快速下拉：关闭，背景随距离变淡。
- 切到另一张图片后关闭：回到该图片对应的缩略图位置；缩略图已离开屏幕时淡出。
- 单图入口：不显示页码。演示中未提供源位置的入口使用淡入淡出；业务入口从图片位置展开并收回。
- 搜索页番剧封面：点击图片只预览，右侧文字仍进入番剧详情；最近更新、热门作品和搜索结果均检查。
- 番剧详情底部面板：顶部封面和点位图片在不同面板高度、滚动位置下，从实际位置展开并收回；关闭预览后保持面板状态。
- 失败入口：保留缩略图，展示重试；重试仍会失败，因为使用了不存在的域名。
- 长按：弹出“保存到相册 / 分享图片”底部菜单。点击遮罩、下滑菜单或 Android 返回键只收起菜单，当前图片和缩放状态保持不变。
- 保存：首次请求添加照片权限，授权后保存当前页原图并提示成功；拒绝后不下载、不保存，可再次长按重试。永久拒绝时提供系统设置入口。
- 分享：菜单完全收起后打开系统分享面板，发送当前页原图文件；无需相册权限。取消分享不提示错误，返回后可继续预览。
- 切到第二、三张后分别保存/分享，确认相册或接收端中的图片及分辨率正确；快速重复点击不应产生多次保存或多个分享面板。
- 断网时已缓存的原图仍可保存/分享；未缓存原图下载失败时提示失败，不能把缩略图当作原图保存。下载时退出预览应取消操作，不应在退出后再弹权限/分享。
- 保存后检查 PNG 透明度、GIF 动画和 JPEG 原始尺寸；无后缀图片链接（演示图）应识别真实格式。Web 显示请使用手机应用的提示。
- 连续打开、退出：初始页码、缩放和加载状态不沿用上一会话。
- iOS 和 Android 分别确认安全区、状态栏及退出后恢复情况。

## 组件接口

### 业务图片入口

`src/components/point-image.tsx` 封装巡礼点的截图/封面选择、缺图提示、缩略图 URL 与原图预览。调用方传入 `image`、`cover`、`title` 和布局属性；可以通过 `children` 添加序号、集数等覆盖层，排序时设置 `previewEnabled={false}`。普通列表无需自行拼接预览地址或编写缺图分支。

`src/components/previewable-image.tsx` 提供 `PreviewableImage`，供 `PointImage` 和番剧封面复用。调用方无需自行包装手势、维护测量 ref 或渲染预览弹窗。

```tsx
<PreviewableImage
  source={{ uri: thumbnailUri }}
  previewUri={originalUri}
  accessibilityLabel={pointTitle}
  style={{ width: 190, height: 120 }}
/>
```

- `source`：含 `uri` 的缩略图源；`previewUri`：原图地址，省略时作为普通占位图，不响应预览手势。
- `style`、`placeholder`、`onLoad` 等常用 Expo Image 属性继续传给内部图片。默认使用 `cover`、居中、磁盘/内存缓存且无缩略图切换动画。
- `containerStyle`：可选，用于包装容器布局，例如百分比尺寸图片需要 `flex: 1`。
- `previewBorderRadius`：可选，匹配外围卡片的裁切圆角；不会修改卡片本身的样式。
- `maxPressDistance`：可选，指定后使用 Tap 手势限制按下后的移动距离，适用于 Mapbox 等不会可靠取消按压的原生容器；默认仍为 `Pressable`。
- 内部统一点击、无障碍激活、图片比例与位置测量。图片实际布局和容器分别测量，无需手动传入首页溢出图片的宽度。切换图片源会重置测量与会话，避免旧图状态沿用。

### 全屏预览

`src/components/image-preview.tsx` 导出 `ImagePreview`、`PreviewImage`、`ImagePreviewBounds` 和 `ImagePreviewProps`。

- `images`：每项包含唯一 `id`、大图 `uri`，以及可选的 `thumbnailUri`、原始 `width` / `height`（正数）。未知尺寸时淡入，加载原图后补齐尺寸。
- `visible`、`initialIndex`、`onClose`：控制显示、初始图片和关闭。收到 `onClose` 后调用方关闭组件。
- `getSourceBounds(index)`：可选，返回对应图片视图的窗口坐标；默认 `contentFit: 'contain'`，可指定 `'cover'`。`borderRadius` 为源容器圆角，`clip` 为额外裁切区域的窗口坐标。`cover` 展开/收回时同步插值裁切框，保持原图比例。没有有效位置时淡入淡出。
- `onIndexChange`：切图回调。
- `onLongPress`：可选，自定义长按行为；提供时覆盖内置保存/分享菜单。

图片列表在一次预览会话中应保持不变；重新打开会重置图库状态。内置菜单使用已有 ActionSheet、Expo MediaLibrary 和 Sharing。优先读取原图磁盘缓存，没有缓存时下载原图；根据文件头补齐真实扩展名，不重编码。下载可在退出时取消，操作期间禁止重复触发；分享副本保留至少一天，在后续操作时清理过期文件，避免接收应用读取时文件已被删除。

相册权限说明已涵盖预览图片；已安装包的系统权限文案仍是旧文案，新文案随以后常规原生构建生效，本次未构建。

## 当前验证范围

用户在迭代中已实测并确认预览组件基本功能可用，随后完成业务接入和问题修复。代理执行 TypeScript、改动文件 ESLint、格式检查及下述自动化测试，不将这些结果视为所有设备场景均已验收。

2026-09-28 经用户授权，通过 ADB 安装用户提供的 `ae85b04` 测试 release APK 对照现象，并在用户启动的 Android 开发包中复测列表、详情面板及缩略图失败入口。日志确认旧逻辑会忽略缩略图尺寸尚未取得时的点击；弹窗首次布局也可能先报告较小高度，再变为全屏高度。当前实现等待弹窗显示及图库布局就绪后再开始动画，并在关闭末帧后移除弹窗。未构建新的 release APK，修复后的 release 效果由用户后续验证；iOS 尚未复测。

一次运行本次迭代全部轻量回归（当前共 31 项）：

```powershell
node --test scripts/tests/*.test.mjs
```

Node 直接加载 TypeScript 时可能提示 `MODULE_TYPELESS_PACKAGE_JSON`；这是测试运行器重新识别 ESM 的提示，不需要为此修改应用的模块配置。地图相关测试和设备回归见 [地图选中标记](./map-marker-rendering.md)。

关闭动画直接作用于图库中已挂载的图片，不切换图片实例。通过图库的 `onUpdate` 抵消内部回弹变换，保持原有收回轨迹；是否收回由缩略图位置与图片尺寸是否有效决定，不依赖原图加载状态。

轻量逻辑测试（本机 Node 24 可直接运行）：`node --test scripts/tests/image-preview-gestures.test.mjs`。覆盖捏合后的双击复原、点击位置换算、图片边界、慢拖/快滑翻页和首尾边界；不替代设备手势验收。

源位置测试：`node --test scripts/tests/image-preview-source.test.mjs`，覆盖原有 contain 过渡、竖图 cover 比例、首页图片比容器更宽时的裁切位置以及无效/离屏位置、未知图片尺寸淡出；补充 TrueSheet 原生偏移、不同面板高度/滚动位置和无触摸事件回退。触摸打开时通过 Gesture Handler 的窗口坐标减局部坐标确定容器起点，尺寸取自已有 `onLayout`，无需再等待一次原生测量；无触摸事件时回退到 `measureInWindow`。每次打开保存该会话起点，避免展开后的布局回调覆盖坐标。设备需检查详情面板两档高度、滚动后封面/巡礼点预览的展开与收回，并回归搜索和地图卡片。
