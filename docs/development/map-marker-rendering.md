# 地图选中标记

## 图层与数据

首页选中圆点由 `SelectedMapPointLayer` 绘制。独立 `selected-map-point-source` 最多包含一个点，取消选中时为空；圆点样式复用普通圆点的原生缩放表达式。

计划地图使用 `SelectedPlanMapPointLayer`：通过 `Mapbox.Image` 将图片、圆角边框、当前点位标签和圆点生成为纹理，再用单个 `SymbolLayer` 绘制。纹理复用一个 ID，在选中内容、图片显示、主题、语言和图片开关变化时刷新。定位、旋转与缩放期间不再同步选中 `MarkerView` 的屏幕位置。点击由 `ShapeSource` 处理；不提供原 Pressable 的按压变淡反馈，点位操作仍可从计划卡片和列表进入。

选中照片与普通缩略图使用相同的 `h160` 地址，并使用 React Native `Image` 对齐 Mapbox 的原生图片加载管线。Android 通过 Fresco 复用缩略图缓存，关闭图片渐显及解码尺寸变换。

`Images` 与 `Mapbox.Image` 从地图首次挂载开始保持注册，地图未就绪时使用透明占位子视图；地图加载完成后才将子根替换为完整 artwork。Android 的 `RNMBXImage` 首次添加子视图时可能尚未拿到地图引用，而后续 `addToMap` 不会补挂该子视图；未挂到窗口的 Fresco 图片不会开始加载，所以仅反复刷新快照无法解决首入空框。提前注册父容器、在地图就绪后替换整个子根，确保照片挂入离屏视图。保留布局快照与 `onLoad` 后的完整照片刷新；设备验收同时覆盖首入、退出重入和连续切点。

首页巡礼点 PopupCard 和附近位置卡片包含图片、导航等交互，使用 `MarkerView`。关闭时卸载对应注解。首页普通点切换时复用一个注解，更新其坐标与卡片内容；附近位置使用点击序号创建独立注解，同一附近位置的行政区更新不会重新创建注解。

2026-11-11 在 Android 模拟器上试验复用首页普通点 `MarkerView`：两个不同位置切换时，录屏连续两帧在旧位置显示了新点名称和图片占位，随后才移到新位置。此结果只覆盖所测模拟器与切换场景；JS 的布局或帧回调不能证明 Mapbox 注解已在目标位置绘制完成。

曾试验短暂保留旧注解直至新注解布局后的双卡交接，近距离切换避免了中间露出底图，但录屏显示新卡出现后旧卡边缘仍短暂可见。根据单卡偏好改为复用单个注解；单卡方案无法保证内容与位置同帧提交，上述错位风险仍存在。

在 Android 模拟器以袋井站附近同一作品的两个相邻点、首页视野截图条和相机平移进行对比：单卡方案未发现整张卡片消失的帧，但切换时可观察到新名称和图片占位先于位置更新。这个结果仅覆盖所测设备和场景，不能保证其他设备、iOS 或不同地图负载下完全无闪。

附近卡片首次打开前先查询当前底图的已渲染地点，将地名、英文名和图标标识一次性写入状态后挂载，避免先显示坐标卡、随后新增名称行使底部锚定的卡片向上跳。未命中地点或查询失败时，首次点击仍显示坐标和附近巡礼点；已有卡片时，仅确认无地点名称才关闭，查询失败保留原卡片。查询期间的后续点击、选点、地图移动和样式变化会使旧结果失效。

首页和计划地图的附近候选都先排除没有截图路径或路径为空白的点，再按距离取最近 3 个；不使用作品封面为无截图点补位。不足 3 个时显示实际数量，没有带截图的候选时隐藏图片行。

计划地图复用同一附近地点识别与卡片 UI，但附近位置由计划页独立管理，不写入首页 `useMapBrowse`，也不替换计划已选点。打开、关闭或切换附近卡片时，底部计划卡与当前点标记保持原状；计划页的空白点击仅切换附近卡片：已开则关闭，未开则显示附近点和坐标。附近候选只来自当前计划成员并跟随计划页作品筛选，不使用首页筛选。点击附近截图走计划原有选点与相机流程，并关闭附近卡片；通过地图点选、列表、底卡切换到不同计划点时也关闭附近卡片，普通操作重新选中同一点、底卡重新定位及筛选作品仍保留附近卡。原有相机策略、完成状态与底部卡相机边距不变。已选 artwork 的命中优先级仍高于底图 POI，跨点查询与本地图标准备保留点击、选择、相机、样式和地图实例的失效保护。

两种模式共用 `SELECTED_MAP_POINT_LAYER_ID` 作为排序锚点。普通圆点、点位缩略图和番剧图标都设置 `belowLayerID`，保证选中标记高于这些图层。选中层始终挂载；新增 marker 图层时也要声明这一关系。该关系不代表选中标记高于 Popup 等原生视图。

附近卡片的底部箭头参与 `MarkerView` 尺寸计算，底部中心锚点落在箭头尖端。标题行至少保留 22 高。图标先按图集元数据的整数像素矩形裁出独立 PNG，再缩放显示，防止相邻图标像素渗入。名称优先使用实际图标主色，缺少主色时按当前 Mapbox 样式的标签图层、要素属性和 zoom 在 JS 中求值；未知表达式回退主题文字色。颜色相对实际卡片背景不足 4.5:1 时调整亮度，因此卫星白色标签在浅色卡片上不会直接使用白字。样式请求按样式去重并持久缓存，过期刷新失败保留旧数据；清除地图缓存也会使在途请求失效。

浏览地图提前预取图集与当前样式。命中地点后只用已有本地图集准备裁图、主色和已解码的 `ImageRef`，准备完成再一次性写入开卡状态；准备期间保留旧卡，后续点击或地图变化仍会使旧任务失效。卡片挂载后不再订阅图集更新，也不再用 `onLoad` 将备用图标和默认文字色替换成最终外观。无本地图集、缺少图标或准备失败时，本次卡片固定使用回退外观，后台下载只供下次打开使用，点击不等待网络。已解码图标缓存最多保留 64 项，淘汰时仅移除引用，不释放仍可能被可见卡片使用的图像。地图文字色同步读取缓存，并按地点、样式和 zoom 固定快照，后台缓存更新及行政区更新不会使已显示标题变色；显式切换地图样式或 zoom 时重新取样。

首页和计划地图的普通点位缩略图沿用“纬度越低越靠上”的顺序。同纬度点位按数据顺序决定上下层级。排序值在图片点位索引建立时生成一次；缩放、视口筛选和图片开关复用该结果。点位数据列表更新时重新建立索引。

番剧图标、普通圆点和首页选中圆点共用固定的 `MAP_MARKER_HITBOX = { width: 12, height: 12 }`，单位为 Android dp / iOS points。查询框以点击位置为中心，在标记可命中区域外提供约每侧 6 个逻辑像素的水平、垂直容错，并非将整个标记的点击区域限制为 12×12。固定逻辑单位让不同屏幕密度上的容错尺度一致，不再按屏幕密度换算来复刻旧版 Android 的物理像素范围。新版 Mapbox 默认 44×44 的查询容差对密集地图偏宽；直接归零则会降低小圆点的点击容错，因此采用 12×12。

点位缩略图保留升级前已有的 `hitbox={{ width: 0, height: 0 }}`；普通圆点由首页和计划地图共用，两处都使用固定的 12×12 容差，计划地图选中 artwork 的可见区域判断保持独立。点击仍按 Mapbox 的渲染要素规则拾取，番剧图标及文字都可命中，不提供图片逐像素透明度检测。

## 切换选中的更新范围

- 首页保留普通点位数据，仅更新单点源，普通圆点由相同样式的选中圆点覆盖。
- 计划地图保留普通圆点及缩略图数据，通过 `MapMarkerSelectionContext` 仅让绘制层更新透明度表达式，隐藏选中点的普通圆点、白边和缩略图。匹配使用番剧 ID 与点位 ID，避免不同作品中的同名 ID 相互影响。
- 普通数据源不订阅选中状态；缩略图的视口和密度筛选不依赖选中点。布局、来源数据或番剧筛选变化仍可触发必要的数据更新。
- 计划地图的普通圆点、缩略图和地图空白点击保持稳定事件回调。选中点、artwork key 和父回调由 `useLayoutEffect` 发布到 ref，事件读取最近一次已提交的数据，避免切点或父回调更新让 `ShapeSource` 再次序列化完整 GeoJSON；未提交的渲染不改变事件快照。异步屏幕投影期间换点、取消选中或切换图片开关时，旧 artwork 命中失效，仍按原逻辑回退到被点击的普通点。地图实例替换或卸载后丢弃旧地图的在途点击。
- 原有选中点查找、相机事件处理和原生样式求值仍有开销，不能将整个交互称为常数开销，也没有真机帧率对比结果。
- 未选中时使用空数据源，避免用恒假过滤表达式模拟空选中状态。
