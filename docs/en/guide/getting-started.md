# Getting Started

## Download and install

Visit the [download page](/en/download) and choose the package for your device:

- **Android**: Select “Download Android APK,” then follow the system prompts to install it.
- **iOS / iPadOS**: Download the unsigned IPA from GitHub Releases and follow the [iOS sideloading guide](/en/guide/ios-sideloading) to sign and install it with your own Apple account.

::: warning Android installation prompt
When downloading an APK from a browser, Android may ask you to allow that browser to install unknown apps. Confirm that the download comes from this project's GitHub Releases page before granting permission.
:::

::: warning iOS installation prompt
An unsigned IPA cannot be installed directly. Sideloading uses a third-party tool, and signatures made with a free Apple account usually need to be refreshed every seven days. Read the complete guide and make sure you accept these limitations before continuing.
:::

## First launch

1. Open the app to enter the map home screen, then pan or zoom to browse pilgrimage spots.
2. Allow location access to quickly return to the area around your current position.
3. Tap a marker to view scene images, anime information, and location details.
4. Add a place to favorites or include it in a pilgrimage plan.

## Plan a pilgrimage

1. Search for an anime title or location.
2. Add target spots to favorites.
3. Create a pilgrimage plan and add the places for this trip.
4. Open the plan map and arrange the visiting order based on their locations.
5. Once on site, use comparison photography to line up your composition.

## Permissions

| Permission               | Purpose                                            | If denied                                                         |
| ------------------------ | -------------------------------------------------- | ----------------------------------------------------------------- |
| Location                 | Show your current position on the map              | You can still browse the map manually                             |
| Camera                   | Take on-site comparison photos                     | Direct capture is unavailable; other browsing features still work |
| Photos and media library | Select reference images and save comparison images | Related images cannot be read or saved                            |

Read the [Privacy Policy](/en/PRIVACY) for more information.

## Troubleshooting

First check your network connection and app version. If the problem continues, search or open a report on [GitHub Issues](https://github.com/boiboif/anitabi-app/issues). Do not attach precise location data, private photos, access tokens, or other sensitive information to a public Issue.
