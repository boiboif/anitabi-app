# 为圣地巡礼设计的每一步

Anitabi 把动画取景地数据放进移动端地图，并围绕真实的出行场景设计浏览、收藏、计划和拍摄体验。

## 地图浏览

- 在世界地图上浏览大量动画巡礼点；
- 按番剧筛选地图内容，减少无关信息；
- 显示带图片的地图标记，更快识别目标地点；
- 查看巡礼点详情并直接跳转到地图导航。

## 搜索与收藏

- 搜索番剧和巡礼点；
- 收藏想去或已经到访的坐标；
- 收藏数据保存在本地，无需注册账号。

## 巡礼计划

把多个巡礼点整理为独立计划，在地图上集中查看。适合在出发前梳理当天路线，也方便旅途中快速切换目标。

## 对比拍摄

在巡礼点现场打开相机，以动画截图作为构图参考。拍摄后可以替换实拍图并生成对比图片，保存到系统相册。

## 深色模式与本地优先

应用支持系统深色模式。收藏、计划、缓存和对比图默认保存在设备本地；定位、相机与照片权限只在对应功能需要时使用。
