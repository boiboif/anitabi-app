# 快速开始

## 下载安装

目前公开下载版本为 Android APK。前往[下载页面](/download)，点击“下载 Android APK”，然后根据系统提示完成安装。

::: warning Android 安装提示
从浏览器下载 APK 时，Android 可能提示允许当前浏览器安装未知来源应用。请确认下载地址来自本项目的 GitHub Releases 页面，再决定是否授权安装。
:::

## 第一次打开

1. 打开应用后进入地图首页，拖动或缩放地图浏览巡礼点。
2. 允许定位权限后，可以快速回到当前位置附近。
3. 点击地图上的标记查看取景图、作品信息和位置详情。
4. 对感兴趣的地点点击收藏，或将它加入一个巡礼计划。

## 规划一次巡礼

1. 在搜索页查找作品或地点。
2. 将目标巡礼点加入收藏。
3. 新建一个巡礼计划，并把本次行程的地点加入计划。
4. 打开计划地图，按位置关系安排访问顺序。
5. 到达现场后使用对比拍摄功能完成构图。

## 权限说明

| 权限 | 用途 | 不授权的影响 |
| --- | --- | --- |
| 定位 | 在地图上显示当前位置 | 仍可手动浏览地图 |
| 相机 | 拍摄现场对比照片 | 无法直接拍摄，其他浏览功能不受影响 |
| 照片与媒体库 | 选择参考图、保存对比图 | 无法读取或保存相关图片 |

更多信息请阅读[隐私政策](/PRIVACY)。
