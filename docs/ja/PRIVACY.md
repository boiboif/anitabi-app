# プライバシーポリシー

最終更新日：2026年11月4日

本ポリシーでは、Anitabi App とプロジェクト公式サイトが利用に関する情報をどのように取り扱うかを説明します。

## 1. データの取り扱い

本アプリにはアカウント機能や広告はなく、ユーザー情報を販売することもありません。お気に入り、巡礼プラン、設定、地図キャッシュ、撮影または生成した比較画像はデフォルトで端末内に保存され、本プロジェクトが所有するサーバーへアップロードされることはありません。

巡礼プランを共有またはインポートするときは、プラン名とスポット識別子が QR コード、共有リンク、またはプランファイルに記録され、ユーザーが選んだシステムの共有先を通じてのみ送信されます。本プロジェクトは中継サーバーを運営していません。

アプリのアンインストールやデータ消去により、これらの内容が削除される場合があります。端末のシステムバックアップに別途コピーが保存される場合もあります。

## 2. 権限

本アプリは、対応する機能を使用するときだけ次の権限を求めます。

- **位置情報**：地図上に現在地を表示します。プランを距離順で表示するときは、端末内で現在地から各スポットまでの直線距離を計算します。
- **カメラ**：巡礼の比較写真を撮影し、巡礼プランの QR コードを読み取ります。
- **写真とメディアライブラリ**：参考画像の選択と生成画像の保存に使用します。

権限は拒否でき、システム設定からいつでも取り消せますが、関連機能が利用できなくなる場合があります。位置情報や画像の内容を、本プロジェクトが所有するサーバーへ能動的にアップロードすることはありません。

プランの距離順表示では、アプリ使用中の位置情報の許可を個別に求めます。距離順表示をオフにしたとき、プラン画面を離れたとき、またはアプリがバックグラウンドに移ったときに、この一覧の位置情報取得を停止します。現在地や計算した距離はプランに書き込まず、移動履歴も保存しません。

## 3. 第三者サービス

本アプリは次の第三者サービスへ接続します。

- **anitabi.cn**：スポット、作品情報、画像を取得します。
- **Mapbox**：地図を読み込みます。
- **Sentry**：クラッシュ、パフォーマンス、アプリバージョン、端末種別などの技術的な診断情報を受信します。個人を特定できる情報（PII）のデフォルト送信は無効にしています。

これらのサービスは、それぞれのプライバシーポリシーに従い、IP アドレス、リクエスト時刻、端末種別など、通信に必要な情報を処理する場合があります。

## 4. 公式サイトのアクセス解析

公式サイトでは、アクセス解析に Umami Cloud と GoatCounter を利用します。Umami は管理者が集計結果を確認するために、GoatCounter はサイト上に累計と直近30日間のページビューを表示するために使用します。ページのパス、ブラウザーや端末に関する技術情報などが両サービスに送信されます。集計するページのパスにはクエリパラメーターとページ内リンクの識別子を含めません。広告の追跡には使用しません。

GoatCounter の公開カウンターでは、サイト全体の集計に加え、ページのパスを知っている人がそのページの集計を確認できる場合があります。個々の訪問者の記録は公開しません。各サービスはリクエストの処理に IP アドレスを使用する場合があります。データの取り扱いについては、[Umami のプライバシーポリシー](https://umami.is/privacy)と [GoatCounter のプライバシーポリシー](https://www.goatcounter.com/help/privacy)をご覧ください。

## 5. ポリシーの変更とお問い合わせ

アプリのデータ処理方法に変更がある場合、本ファイルを更新します。プライバシーに関するご質問は、本リポジトリの Issue からメンテナーへお問い合わせください。
