# Anitabi API メモ

このページは、anitabi.cn のアニメ聖地巡礼マップが公開しているデータと、その構造を調査した開発者向けメモです。Anitabi App は、作品情報、巡礼スポット、画像などを anitabi.cn の公開インターフェースから取得して表示します。

## 主なデータ

- `g0.json` ～ `g5.json`：作品ごとのテーマ、スポット詳細、画像、メモなど。
- `g.json`：作品情報、代表地点、ズーム、スポットの座標と優先度など。
- スポットには ID、名称、座標、画像、エピソード、メモ、フォルダーなどが含まれる場合があります。
- 作品にはタイトル、都市、色、カバー、分類、代表座標、スポット一覧などが含まれる場合があります。

このインターフェースは第三者サービスによるもので、形式や提供状況が予告なく変わる可能性があります。実装時は欠損値と取得失敗を考慮してください。
