# アニメ聖地巡礼の一歩一歩を支える機能

Anitabi はアニメの舞台データをモバイル地図にまとめ、実際の旅に合わせて閲覧、お気に入り、計画、撮影の体験を設計しています。

## 地図で探す

- 世界地図から多数のアニメ聖地スポットを閲覧できます。
- 作品ごとに地図上のスポットを絞り込めます。
- 巡礼スポットの分布と関連画像を確認できます。
- スポット詳細から地図アプリのナビゲーションを直接開けます。

## 検索とお気に入り

- 作品や巡礼スポットを検索できます。
- 行きたい場所や訪れた場所をお気に入りに保存できます。
- お気に入りは端末内に保存され、アカウント登録は不要です。

## 巡礼プラン

複数のスポットを個別のプランにまとめ、地図上で一度に確認できます。出発前に一日の行程を整理したり、旅先で次の目的地へすばやく切り替えたりするのに便利です。

## 比較撮影

現地でカメラを開き、アニメの場面を構図の参考として表示できます。撮影後は実写画像を差し替えて比較画像を作成し、端末の写真ライブラリに保存できます。

## ダークモードとローカルファースト

システムのダークモードに対応しています。お気に入り、プラン、キャッシュ、比較画像はデフォルトで端末内に保存され、位置情報、カメラ、写真の権限は対応する機能を使うときだけ利用します。

::: tip 継続的に開発中
巡礼プランは QR コード付き画像として共有でき、大きなルートはプランファイルからインポートできます。AI を活用したルート計画なども今後追加予定です。[GitHub Issues](https://github.com/boiboif/anitabi-app/issues) からご意見をお寄せください。
:::
