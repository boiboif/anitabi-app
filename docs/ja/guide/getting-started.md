# はじめに

## ダウンロードとインストール

[ダウンロードページ](/ja/download)から、お使いの端末に合ったパッケージを入手してください。

- **Android**：「Android APK をダウンロード」を選び、システムの案内に従ってインストールします。
- **iOS / iPadOS**：GitHub Release から未署名 IPA をダウンロードし、[iOS サイドロードガイド](/ja/guide/ios-sideloading)に従ってご自身の Apple アカウントで署名・インストールします。

::: warning Android のインストールについて
ブラウザから APK をダウンロードすると、Android が「不明なアプリのインストール」を許可するよう求める場合があります。ダウンロード元が本プロジェクトの GitHub Releases であることを確認してから許可してください。
:::

::: warning iOS のインストールについて
未署名 IPA は直接インストールできません。サイドロードには第三者ツールを使用し、無料の Apple アカウントによる署名は通常 7 日ごとに更新が必要です。事前にガイド全体を読み、制限を理解したうえで進めてください。
:::

## 初回起動

1. アプリを開くと地図ホームが表示されます。地図を移動・拡大縮小して巡礼スポットを探します。
2. 位置情報へのアクセスを許可すると、現在地周辺へすばやく戻れます。
3. 地図上のマーカーをタップすると、場面画像、作品情報、スポット詳細を確認できます。
4. 気になる場所をお気に入りに追加するか、巡礼プランへ登録します。

## 巡礼を計画する

1. 検索画面で作品や場所を探します。
2. 目的の巡礼スポットをお気に入りに追加します。
3. 新しい巡礼プランを作成し、今回の旅で訪れる場所を追加します。
4. プランの地図を開き、位置関係を見ながら訪問順を決めます。
5. 現地に着いたら比較撮影機能で構図を合わせます。

## 権限について

| 権限                     | 用途                           | 許可しない場合                                   |
| ------------------------ | ------------------------------ | ------------------------------------------------ |
| 位置情報                 | 地図上に現在地を表示           | 地図は手動で閲覧できます                         |
| カメラ                   | 現地で比較写真を撮影           | 直接撮影できませんが、その他の閲覧機能は使えます |
| 写真・メディアライブラリ | 参考画像の選択、比較画像の保存 | 関連画像の読み込みや保存ができません             |

詳しくは[プライバシーポリシー](/ja/PRIVACY)をご覧ください。

## 問題が発生した場合

まずネットワーク接続とアプリのバージョンをご確認ください。解決しない場合は [GitHub Issues](https://github.com/boiboif/anitabi-app/issues) で既存の報告を検索するか、新しい Issue を作成してください。正確な位置情報、個人の写真、アクセストークンなどの機密情報は公開 Issue に添付しないでください。
