# iOS でサイドロードする

Anitabi の iOS 版は未署名 IPA として公開しています。ご自身の Apple アカウントを使い、サイドロードツールで署名してからインストールします。脱獄は不要で、無料の Apple アカウントも利用できます。

## インストール方法を選ぶ

| 方法                                        | おすすめの利用者                                                 | 署名の更新方法                                                                     |
| ------------------------------------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| [Sideloadly](#sideloadly)                   | 初めてサイドロードする方、普段からコンピューターを使う方         | USB または同じネットワークで端末とコンピューターを接続して更新                     |
| [SideStore](#sidestore)                     | 日常の署名更新を端末だけで行いたい方                             | 初回はコンピューターでインストールし、その後は Wi-Fi と LocalDevVPN に接続して更新 |
| [LiveContainer + SideStore](#livecontainer) | サイドロードに慣れていて、複数のアプリをコンテナ内で実行したい方 | SideStore でコンテナの署名を更新。追加設定が必要                                   |

初めてインストールする場合は **Sideloadly** をおすすめします。SideStore や AltStore を設定済みの場合は、以下でダウンロードする IPA をそのままインポートできます。

::: info 無料アカウントの制限
署名の有効期間は **7 日間**です。期限切れ後はアプリを開けなくなるため、署名を更新する必要があります。無料アカウントで署名したアプリは、1 台の端末に同時に **3 個**までインストールでき、SideStore 自体も 1 個に数えられます。自動更新にも各ツールの動作条件があり、永久に有効になるわけではありません。詳しくは [Apple アカウントの制限](https://developer.apple.com/help/account/basics/about-your-developer-account)をご覧ください。
:::

::: warning はじめる前に
サイドロードは App Store や TestFlight による配布ではありません。Sideloadly などのツールは第三者製で、Anitabi や Apple とは関係ありません。必ず公式サイトから入手し、Apple アカウントのパスワード、確認コード、復旧キーを Anitabi のメンテナーや第三者に渡さないでください。
:::

## 必要なもの

- Windows または macOS のコンピューター
- iOS / iPadOS 16.4 以降の iPhone または iPad と、安定してデータ通信できるケーブル
- ログインと 2 ファクタ認証ができる Apple アカウント。署名に使ったアカウントを覚えておいてください。
- [Anitabi GitHub Releases](https://github.com/boiboif/anitabi-app/releases) の **Assets** からダウンロードした `anitabi-app-*-unsigned.ipa`。`Source code` の圧縮ファイルや Android 用の `.apk` ではありません。

IPA は Android APK のようにタップするだけではインストールできません。Sideloadly ではコンピューター上のファイルを選びます。SideStore と LiveContainer では、IPA を端末の「ファイル」アプリに保存してから、それぞれのインポート機能で選択します。

## 方法 1：Sideloadly を使う {#sideloadly}

### 1. コンピューターにツールをインストールする

[Sideloadly 公式サイト](https://sideloadly.io/)から Windows または macOS 用をダウンロードします。Windows では、公式サイトのリンクからデスクトップ版 iTunes と iCloud もインストールしてください。**Microsoft Store 版は使用しないでください。** これは Sideloadly の要件です。SideStore で使う iloader については、そちらのインストール手順に従ってください。

### 2. 端末を接続して IPA をインストールする

1. データ通信対応ケーブルで iPhone または iPad を接続し、ロックを解除します。「このコンピュータを信頼しますか？」と表示されたら「信頼」を選び、端末のパスコードを入力します。
2. Sideloadly を開き、**iDevice** にインストール先の端末が表示されていることを確認します。
3. 左側の IPA アイコンから `anitabi-app-*-unsigned.ipa` を選ぶか、ファイルをウィンドウへドラッグします。
4. **Apple ID** に署名用アカウントのメールアドレスを入力します。自動更新の設定を有効にしたまま、**Start** をクリックします。
5. 案内に従ってパスワードと 2 ファクタ認証の確認コードを入力します。**Done.** と表示されるまで接続を維持してください。
6. 下の[初回起動の設定](#first-launch)に従って開発元を信頼し、デベロッパモードを有効にしてから、ホーム画面で Anitabi を開きます。

### 3. 署名の自動更新を設定する

コンピューターの電源が入り、**Sideloadly Daemon** が動作していて、端末を検出できる必要があります。USB 接続ならそのまま更新できます。Wi-Fi 経由で更新する場合は、まずケーブルでペアリングし、次の設定を行います。

- **Windows**：iTunes の端末の「概要」で「Wi-Fi 経由でこのデバイスと同期」を有効にし、適用して同期します。
- **macOS**：Finder で端末を選び、「一般」で「Wi-Fi がオンのときにこのデバイスを表示」を有効にし、適用して同期します。

以後はコンピューターと端末を同じネットワークに接続します。端末が見つからない場合はロックを解除して画面を点灯させるか、USB 接続を試してください。7 日目になる前に署名が更新されていることを確認しましょう。コンピューターを長期間使わない場合は、手動で接続して再度サイドロードしてください。詳しくは [Sideloadly FAQ](https://sideloadly.io/faq)をご覧ください。

## 方法 2：SideStore を使う {#sidestore}

SideStore の初回インストールにはコンピューターが必要です。設定後は、普段のインストールや署名更新を端末だけで行えます。以下は [SideStore 公式インストールガイド](https://docs.sidestore.io/docs/installation/install)に沿った手順です。

### 1. iloader と LocalDevVPN をインストールする

1. コンピューターで [iloader 公式サイト](https://iloader.app/)からツールをダウンロードし、インストールします。Windows の iTunes などは [SideStore の準備手順](https://docs.sidestore.io/docs/installation/prerequisites)に従って設定してください。
2. iPhone または iPad に [LocalDevVPN](https://apps.apple.com/app/localdevvpn/id6755608044) をインストールし、VPN 構成の追加を許可して接続します。利用中の App Store の地域で入手できない場合は、SideStore の公式ドキュメントで利用可能な入手方法を確認してから、この方法を使うか判断してください。
3. 端末を **Wi-Fi** に接続します。モバイルデータ通信だけでは SideStore の要件を満たしません。インストール、アップデート、署名更新の間は LocalDevVPN にも接続してください。

### 2. SideStore をインストールして初期設定する

1. ケーブルで端末を接続し、ロックを解除してコンピューターを信頼します。
2. iloader を開いて Apple アカウントにログインし、端末を選んで **Install SideStore (Stable)** をクリックします。
3. インストール後、[初回起動の設定](#first-launch)に従って開発元を信頼し、デベロッパモードを有効にします。
4. Wi-Fi と LocalDevVPN の接続を確認して SideStore を開き、iloader と同じ Apple アカウントでログインします。
5. **My Apps** で SideStore の右側にある残り日数をタップし、最初に SideStore 自体の署名を更新します。証明書の取り消しや新規作成を求められた場合は、公式手順に従って **Yes** または **Refresh Now** を選びます。更新中にホーム画面へ戻ることがあります。数秒待ってから開き直してください。

### 3. Anitabi をインポートする

1. 端末で IPA をダウンロードして「ファイル」アプリに保存するか、コンピューターから転送して「ファイル」に保存します。
2. SideStore の **My Apps** を開き、**+** から `anitabi-app-*-unsigned.ipa` を選んで、インストール完了を待ちます。
3. ホーム画面に戻って Anitabi を開きます。日常の署名更新は、Wi-Fi と LocalDevVPN に接続した状態で **My Apps → Refresh All** を実行し、SideStore と Anitabi の両方の残り日数が更新されたことを確認してください。

LocalDevVPN は SideStore のインストールや署名更新で使うものです。普段 Anitabi を開くために常時有効にする必要はありません。SideStore 自体が期限切れで起動できない場合は、コンピューターへ再接続し、iloader で再インストールする必要があります。

## 上級者向け：LiveContainer + SideStore {#livecontainer}

LiveContainer はアプリをコンテナへインポートして実行します。インポートしたアプリがそれぞれ通常のサイドロード枠を使うことはありませんが、**コンテナ自体の署名と更新は必要です**。ホーム画面へ直接インストールする方法とは動作環境が異なります。このガイドでは Anitabi のコンテナ内での完全な互換性を検証していないため、初めての場合は上の 2 つの方法をおすすめします。

### 1. 統合版をインストールする

前述の SideStore の準備手順に従って、最新版の iloader と LocalDevVPN をインストールし、端末を接続します。iloader で **LiveContainer+SideStore** を選び、[初回起動の設定](#first-launch)を完了してください。統合版全体でサイドロード枠を 1 つ使います。先に単体版 SideStore をインストールする必要はありません。

### 2. 内蔵 SideStore と証明書を設定する

1. Wi-Fi と LocalDevVPN に接続した状態で LiveContainer を開き、**Apps** ページから内蔵 SideStore に移動します。
2. SideStore の設定で、署名に使った Apple アカウントにログインします。以前の設定を引き継いでログイン済みと表示される場合は、一度ログアウトしてからログインし直してください。
3. **My Apps** で **Refresh All** をタップします。更新完了後、内蔵 SideStore を終了して LiveContainer を開き直します。
4. LiveContainer の設定で **Import Certificate from SideStore**（SideStore から証明書をインポート）を選び、確認します。ボタンが **Remove Certificate** に変わればインポート完了です。**JIT-Less Mode Diagnose** でも設定を確認できます。

### 3. Anitabi をインポートして起動する

**LiveContainer の Apps ページ**へ戻り、**+** から「ファイル」にある Anitabi の IPA を選びます。インポート後はコンテナ内のアプリ一覧から起動してください。ここでは LiveContainer にインポートします。内蔵 SideStore で Anitabi を直接インストールすると、通常のサイドロード枠を使います。

以後は内蔵 SideStore の **Refresh All** でコンテナの署名を更新します。証明書のインポートや実行で問題が起きた場合は、[LiveContainer + SideStore 公式ガイド](https://livecontainer.github.io/docs/installation/lc_sidestore)と[コンテナ内アプリの FAQ](https://livecontainer.github.io/docs/faq/using-guest-apps)をご覧ください。

## 初回起動の設定 {#first-launch}

### 開発元を信頼する

「設定 → 一般 → VPN とデバイス管理」を開き、「デベロッパ App」で署名に使った Apple アカウントを選択して「信頼」をタップし、確認します。新しい iOS では「許可して再起動」と表示される場合があります。画面の案内に従ってください。

### デベロッパモードを有効にする

Anitabi が対応する iOS / iPadOS では、このような開発用署名のアプリにデベロッパモードが必要です。「設定 → プライバシーとセキュリティ → デベロッパモード」を有効にし、案内に従って再起動します。ロックを解除し、もう一度有効にすることを確認してください。

項目が見つからない場合は、コンピューターに接続してペアリングし、インストールを試してから設定を確認してください。コンピューターの信頼、開発元の信頼、デベロッパモードの有効化はそれぞれ別の操作です。詳しくは [Apple のデベロッパモードの説明](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)をご覧ください。

## アップデートとデータの保持

**署名の更新**は、現在のアプリを使える期間を延長する操作です。**インストールパッケージの更新**には新版の IPA のインポートが必要で、サイドロードツールの署名更新ではパッケージは更新されません。Anitabi が対応する互換性のある OTA アップデートは引き続きアプリ内の案内に従って適用でき、そのために IPA を再インポートする必要はありません。

1. アップデートやインストール方法の変更前に、Anitabi の「マイページ → バックアップと復元 → バックアップを書き出す」から重要なデータを保存します。巡礼記録や写真を残したい場合は、それらもバックアップに含め、アプリの外にバックアップを保存してください。
2. [GitHub Releases](https://github.com/boiboif/anitabi-app/releases) から新版の `*-unsigned.ipa` をダウンロードします。
3. 以前と同じツール、Apple アカウント、アプリ識別子（bundle ID）を使って上書きインストールします。識別子を不用意に変えたり、先に旧版を削除したりしないでください。Sideloadly では引き続き自動更新を有効にし、SideStore では **+** から新版の IPA を再度インポートします。

同じアカウントとアプリ識別子であれば通常はローカルデータを保持できますが、バックアップの代わりにはなりません。直接サイドロードした場合と LiveContainer 内では保存先が異なるため、インストール方法を切り替えてもデータが自動移行されるとは限りません。期限切れでアプリを開けない場合は、まず元のアカウントで上書きして署名を更新し、再び開けるようになってからバックアップしてください。

## よくある質問

### IPA をタップしても何も起こりません

正常です。Sideloadly、SideStore、LiveContainer のいずれかでファイルをインポートしてください。ブラウザや「ファイル」アプリで直接タップしてもインストールできません。

### 開発元が信頼されていない、またはデベロッパモードが必要と表示されます

[初回起動の設定](#first-launch)に従ってください。「VPN とデバイス管理」に該当するアカウントがない場合は、まずツール上でインストールが成功していることを確認してください。

### 「App を検証できません」または「App は利用できません」と表示されます

署名の期限切れを確認し、端末をネットワークに接続して開発元の信頼状態を確認します。元のツールと Apple アカウントで署名を更新するか、上書きインストールしてください。SideStore も開けない場合は、先にコンピューターを使って SideStore を復旧します。期限切れを理由に Anitabi を削除するとローカルデータを失うため、削除しないでください。

### Sideloadly が端末を認識しません

端末のロックが解除され、コンピューターを信頼していることを確認してください。データ通信対応の別のケーブルや USB ポートもお試しください。Windows では、iTunes と iCloud が Sideloadly 公式サイトから案内されたデスクトップ版であることも確認してください。

### SideStore でインストールや署名更新ができません

端末が Wi-Fi と LocalDevVPN に接続されていることを確認し、競合する可能性がある他の VPN を一時的に切断してください。特に iOS のアップデートやリセット後にペアリングファイルの失効が表示される場合は、コンピューターへ再接続し、[SideStore のペアリングファイル復旧手順](https://docs.sidestore.io/docs/advanced/pairing-file)に従ってペアリングを復旧してください。

### アプリ数または App ID の上限に達したと表示されます

- **インストール済みアプリ数の上限**：無料アカウントでは、1 台の端末に同時にインストールできるサイドロードアプリは最大 3 個で、SideStore も含まれます。バックアップ後、使っていないサイドロードアプリを削除してください。
- **App ID の上限**：無料アカウントで登録できる短期 App ID は最大 10 個で、7 日後に失効します。アプリの拡張機能も ID を使う場合があります。アプリを削除しても App ID はすぐに解放されないため、期限切れを待つ必要があります。bundle ID を繰り返し変更して再試行しないでください。

### 上書きインストールに失敗します

同じ Apple アカウントと bundle ID を使っているか確認し、ツールの具体的なエラーを調べてください。旧版の削除と再インストールは、バックアップを保存し、復元できることを確認してから検討してください。アプリを削除するとローカルデータも削除されます。
