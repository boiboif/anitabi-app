# iOS でサイドロードする

Anitabi の GitHub Release では未署名 IPA を提供しています。iOS は未署名アプリを実行できないため、「ファイル」アプリ、ブラウザ、AirDrop から IPA を開くだけではインストールできません。サイドロードツールは、ご自身の Apple アカウントを使って IPA に一時的な署名を行い、端末へインストールします。

::: warning はじめる前に
サイドロードは App Store や TestFlight による配布ではありません。Sideloadly などのツールは第三者製で、Anitabi や Apple とは関係ありません。必ず公式サイトから入手し、Apple アカウントのパスワード、確認コード、復旧キーを Anitabi のメンテナーや第三者に渡さないでください。
:::

## 必要なもの

- Windows または macOS のコンピューター
- iOS / iPadOS 16.4 以降の iPhone または iPad と、データ通信に対応したケーブル
- 2 ファクタ認証を有効にした Apple アカウント（無料アカウントも利用できます）
- [Anitabi GitHub Releases](https://github.com/boiboif/anitabi-app/releases) からダウンロードした `anitabi-app-*-unsigned.ipa`
- [Sideloadly 公式サイト](https://sideloadly.io/) からダウンロードしてインストールした Sideloadly

Windows では、Sideloadly が指定するデスクトップ版 iTunes と iCloud も必要です。Sideloadly 公式サイトに掲載されたリンクから入手し、Microsoft Store 版は使用しないでください。

## Sideloadly でインストールする

1. ケーブルで iPhone または iPad をコンピューターへ接続し、端末のロックを解除します。
2. 「このコンピュータを信頼しますか？」と表示された場合は「信頼」を選び、端末のパスコードを入力します。
3. Sideloadly を開き、端末名が一覧に表示されていることを確認します。
4. ダウンロードした `*-unsigned.ipa` を Sideloadly へドラッグするか、IPA アイコンからファイルを選択します。
5. 署名に使う Apple アカウントのメールアドレスを入力し、**Start** を選びます。
6. 画面の案内に従ってログインと 2 ファクタ認証を完了し、インストール完了まで待ちます。
7. 開発者モードを求められた場合は、「設定 → プライバシーとセキュリティ → デベロッパモード」を開き、案内に従って再起動して有効にします。
8. 初回起動時に開発元が信頼されていないと表示された場合は、「設定 → 一般 → VPN とデバイス管理」で該当する Apple アカウントを選び、信頼します。
9. ホーム画面へ戻り、Anitabi を開きます。

ローカルにインストールした開発用アプリを実行するには、Apple の開発者モードが必要です。通常、この項目は端末をコンピューターとペアリングするか、初めてインストールを試みた後に表示されます。表記は iOS のバージョンにより異なる場合があります。[Apple の開発者モードに関する説明](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)もご確認ください。

## 有効期限、更新、アップデート

Apple Developer Program に参加していない無料アカウントには、次の制限があります。

- 署名と provisioning profile の有効期間は通常 7 日間で、期限切れ後はアプリを開けません。
- 1 台の端末に無料アカウントで同時にインストールできるアプリは最大 3 個です。
- 期限前に自動更新するか、期限切れ後に同じ IPA を再度サイドロードする必要があります。

Sideloadly は、コンピューターと端末が USB または同じネットワークで接続されているとき、自動更新を試行できます。Anitabi をアップデートする際は、以前と同じ Apple アカウントと bundle ID で新しい IPA をサイドロードすると、通常はローカルデータを残したまま上書きできます。それでも重要なデータは事前にバックアップし、バックアップなしで旧バージョンを削除しないでください。

無料アカウントの制限については [Apple Developer アカウントの説明](https://developer.apple.com/help/account/basics/about-your-developer-account)、自動更新については [Sideloadly FAQ](https://sideloadly.io/faq)をご覧ください。

## その他のサイドロードツール

SideStore、AltStore、または信頼できる別のツールを設定済みの場合は、同じ未署名 IPA をインポートできます。いずれも Apple アカウントまたは開発者証明書で署名するもので、未署名アプリをそのまま実行可能にするものではありません。利用するツールの公式ドキュメントに従ってください。

## よくある質問

### IPA をタップしても何も起こりません

正常です。未署名 IPA は Android APK のように直接インストールできず、先にサイドロードツールで署名する必要があります。

### 「App を検証できません」または「App は利用できません」と表示されます

署名の期限が切れているか、端末が一時的に署名を検証できない可能性があります。端末をネットワークへ接続し、同じ Apple アカウントで再度サイドロードして、「VPN とデバイス管理」の信頼状態も確認してください。

### Sideloadly が端末を認識しません

端末のロックが解除され、コンピューターを信頼していることを確認してください。データ通信対応の別のケーブルや USB ポートもお試しください。Windows では、iTunes と iCloud が Sideloadly 公式サイトから案内されたデスクトップ版であることも確認してください。

### アプリ数の上限に達したと表示されます

無料アカウントでは、1 台の端末へ同時にインストールできるサイドロードアプリは最大 3 個です。使っていないアプリを削除するか、Apple Developer Program に参加しているアカウントをご利用ください。

### 上書きインストールに失敗します

旧バージョンが別の Apple アカウントまたは異なる bundle ID で署名されている可能性があります。アプリ内の重要なデータをバックアップしてから旧バージョンを削除し、再インストールしてください。アプリを削除するとローカルデータも削除されます。
