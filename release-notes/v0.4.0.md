# Anitabi v0.4.0

本次正式版汇总了 v0.3.1 以来的更新。

## 主要更新

- 新增 3D 建筑地图模式。首页地图和巡礼计划地图都可以一键开启或关闭；放大到城市街区后，建筑会按地图数据中的高度显示，并可通过倾斜视角查看。
- 新增简体中文、日语和英语支持，可在应用内切换语言。
- 重构巡礼计划入口、列表和详情页。计划点位支持排序、未完成筛选，并显示序号及更完整的点位信息。
- 大幅改进巡礼计划地图：新增点位卡片和列表面板，可在点位间切换、重新定位、拍摄对比照片、打开导航，以及标记完成状态。

## 地图与使用体验

- 地图底图可跟随应用深色模式；优化选中点位、图片标记、比例尺和地图控件在不同主题下的显示。
- 优化计划地图中的点位切换与列表定位，减少图片切换时的闪烁，并改善大量点位时的滚动表现。
- 调整巡礼点排序交互及列表滚动和回收，提升浏览体验。

## 文档与发布

- 更新中文文档，并新增英语、日语文档及 iOS 侧载指南。
- 完善 Android 测试构建与正式发布流程，并改进 Android、iOS 热更新配置。

Android 安装包为 arm64-v8a APK。iOS 提供未签名 IPA，安装前需要自行签名；详情请参阅项目文档中的侧载指南。
