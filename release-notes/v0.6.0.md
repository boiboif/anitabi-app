# Anitabi v0.6.0

本次正式版重点优化地图与作品详情的操作体验，并改进启动和更新提示。

## 地图与作品详情

- 优化启动阶段的加载流程，提高 App 启动速度；缓存作品图标裁剪结果，减少重复处理。
- 调整地图点位图片的层级与筛选计算，减少切换点位时的闪现和近景选点抖动。
- 打开作品详情时无需重建整份地图点位数据。
- 优化作品详情抽屉打开和切换时的列表更新，修正图层顺序；修复抽屉打开过程中按返回键误提示退出应用的问题。

## 巡礼计划与图片

- 修复计划地图近景选点时缩放变化、相邻点位图片误选及选中标记偏移的问题。
- 优化计划地图选点与切换点位时的相机和点位显示。
- 修正图片预览中原图尚未加载时的来源图片过渡。

## 更新提示与维护

- 更新弹窗按已安装版本展示本次更新；适用时只补充最近一次尚未安装的重点更新。
- 更新 Expo SDK 57 的部分补丁依赖及 `react-native-view-shot` 等原生依赖。
- 移除 Web 平台支持，后续应用版本面向 Android 和 iOS。

Android 提供 arm64-v8a APK 和 SHA-256 校验文件。iOS 提供未签名 IPA，安装前需要自行签名；参阅[安装指南](https://github.com/boiboif/anitabi-app/blob/main/docs/guide/ios-sideloading.md)。本次更新不强制安装。
