# Anitabi v0.7.0

巡礼相机升级，把动画里的风景拍成你的专属纪念。

## 巡礼相机升级

- **拍摄时：** 新增拍摄比例选择，默认自动匹配巡礼图；优化界面布局，横竖构图更自由。替换参考图后可一键恢复原图。
- **拍摄后导出：** 可添加名字、拍摄时间、地点、作品等巡礼信息，生成专属巡礼图，并支持自定义边框颜色与宽度。权限允许时保存至「Anitabi」相册，方便收藏与分享。

## 新增备份

- 收藏与巡礼计划可导出备份，恢复时支持合并或覆盖，保留点位顺序与完成状态。
- 备份不包含图片文件和地图缓存。

## 修复与改进

- 优化作品详情关闭动画，修复计划列表筛选闪动，并改进多处使用细节。

Android 提供 arm64-v8a APK 和 SHA-256 校验文件。iOS 提供未签名 IPA，安装前需要自行签名；参阅[安装指南](https://github.com/boiboif/anitabi-app/blob/main/docs/guide/ios-sideloading.md)。本次更新不强制安装。
