# Anitabi v0.8.0

这次更新围绕日常巡礼体验，集中打磨了地图、列表和拍照导出的许多细节，并针对大量点位的巡礼计划做了多项性能优化。批量整理点位、查看附近地点和备份数据也更方便了。

## 全新应用图标

- Anitabi 换上全新设计的应用图标，并同步更新开屏展示。

## 性能优化与细节打磨

- 优化大量点位计划的列表展示、批量添加、距离排序与分享处理，改善大计划反复进入地图时的卡顿。
- 改进地图定位、点位图片点击，以及作品详情与地图聚焦的衔接，让浏览和选点更顺手。
- 统一列表卡片、页面背景和地图按钮的样式与交互，调整按钮尺寸、点击反馈与页面留白。

## 巡礼计划升级

- 支持按作品全部点位或作品现有分组批量加入计划，已有点位自动跳过。
- 新增「列表设置」，可仅显示未完成点位，或按当前位置到各点的直线距离由近到远查看；距离排序不会改变已保存的计划顺序。
- 整理模式支持多选、全选与批量删除，保留拖动调整顺序。
- 点位较多、无法生成导入二维码的展示海报新增 Anitabi 下载二维码；导入计划仍可分享计划文件。

## 巡礼相机导出

- 支持「上下」「左右」图片布局，可让参考图与照片使用相同比例，并选择「填满」或「完整」显示参考图。
- 四周边框与中间边框可独立开关。
- 改进导出预览、配置切换、名字输入和边框滑块的交互。

## 分类备份与恢复

- 可选择单独备份收藏、巡礼计划，或同时备份。
- 恢复时仅处理备份中包含的数据类别，未包含的类别保持不变，支持合并与覆盖。
- 兼容旧版备份；新版导出的备份需在 v0.8.0 及以上版本恢复。

## 基础框架与依赖升级

- 升级至 Expo SDK 58，同步更新 React Native 0.88、React 19.3 及 Expo 配套模块。
- 更新 Mapbox、Reanimated、Worklets、Sentry、i18next 等一系列依赖库，并完成新版 SDK 的兼容适配。
- 本次包含原生依赖升级，需要通过新版应用整包更新。

## 修复与改进

- 修复地图旋转、开启 3D 视角时的可见点位数量统计。
- 修复计划地图首次进入时选中图片可能空白的问题。
- 修复搜索分类切换时的列表滚动问题。
